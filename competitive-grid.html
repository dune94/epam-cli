★   Unique to epam-cli — no equivalent in any OSS framework
  • Ralph Wiggum Loop Parallel N-agent error recovery with 5 fix strategies (minimal_change, refactor_approach, alternative_impl, dependency_fix, configuration_fix), quality scoring, file-system snapshots, and first-to-succeed cancellation.
  • OpenSpec / Speckit Autonomous spec-refinement pre-pass per story before any implementation begins. Coordinator decides which spec personas run; acceptance criteria are merged back into the PRD.
  • Failure Pattern Memory Agents are instructed to write a KB entry to KB.md on every retry, documenting root cause and fix. On subsequent stories, semantic search (text-embedding-3-small cosine similarity) retrieves relevant entries and injects them into the agent prompt. Learning compounds across runs.
  • Dynamic Behavioral Contracts Per-story constitution rules loaded from .epam/constitution-rules.json, matched on agent role or required skills. Non-overridable by story prompts — enforced at prompt-assembly time.
  • LLM Topology Routing A single cheap LLM call (Haiku) analyses story metadata, effort, dependency edges, and file-overlap signals to decide single / parallel / sequential execution mode. Decision and reasoning logged to phase-cost.jsonl.
  • CPA + EMA Cost Calibration Cost-per-agent forecasting with exponential-moving-average calibration from actuals, bucketed by model and invoke mode. Includes pipeline-overhead ratio so forecasts reflect total cost, not just story cost.
  • Jira Webhook Pipeline HMAC-verified inbound triggers with 45-second debounced batching, urgent-event bypass, queue persistence, and writeback to Jira at 4 pipeline milestones (spec pass, estimate, story complete, review done).
  • Real-time Budget Enforcement Hard budget check after every LLM response — not session-level tracking. Actions: warn, auto-downgrade model, or hard-pause requiring approval. Prevents runaway spend mid-orchestration.
  • Reviewer-Gated Self-Healing A dedicated reviewer agent (prd-change-reviewer / kb-change-reviewer) validates every automated write to prd.json or profiles.json — AC/TC patches, spec-pass rewrites, CPA estimates, skill-assessment profile creation, model assignment — with a before/after snapshot and revert-on-reject. No other framework gates its own self-modifying writes with a second agent.
  • Rung-Based Inference Ladder Four-rung retry escalation: same-model effort increase first (cheap), then a configurable cross-provider model escalation (EPAM_MODEL_LADDER), with a final-fallback safety net and skip-ahead logic when a healing strategy is already known to be broken.
  • Post-Implementation Test Criteria Acceptance criteria are written before the code exists, so they're necessarily abstract. The TC writer runs after the paired implementation story completes, reads the actual source, and extracts verified facts — exact function signatures, error message strings, mock strategy, banned patterns — into the test story's testCriteria field. The test-engineer agent then writes tests against verified behavior instead of guessing at implementation details from prose, closing a failure mode most agentic frameworks don't model at all: test-writers hallucinating APIs that don't match what was actually built.
✗   Genuine remaining gaps (3)
  • Auto-PR (not auto-commit) Each completed story is auto-committed to its branch. What's missing is the next step: an automatic gh pr create to open a reviewable pull request. OpenHands and SWE-agent do this natively — it closes the loop to a reviewable PR without manual intervention.
  • Multimodal input No vision support. Cannot accept Figma exports, hand-drawn wireframes, screenshots, or design files as story inputs. Increasingly relevant for frontend and UI stories.
  • Python ecosystem TypeScript narrows the addressable universe of integrations — HuggingFace, Pydantic AI, and the broader ML/AI tooling world are Python-first. This is a deliberate architectural choice, not an oversight.
